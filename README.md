# Site do Corinthians - HTML, CSS e JavaScript

Este é um projeto simples de um site estático para o **Corinthians**, feito utilizando **HTML**, **CSS** e **JavaScript**. O site é uma recriação do layout do time de futebol, com informações sobre o clube, notícias e outros conteúdos interativos.

## Tecnologias Utilizadas

- **HTML**: Estruturação da página com a marcação semântica.
- **CSS**: Estilo e layout da página com foco em responsividade.
- **JavaScript**: Interatividade, como transições e eventos dinâmicos.

## Funcionalidades

- Página inicial com informações sobre o time.
- Seções sobre história, conquistas, elenco e notícias.
- Efeitos interativos e animações simples com JavaScript.
